# Страницы и функции Telegram бота для учета расходов

## Главная reply-клавиатура

```
[📊 Обзор месяца] [📅 Сегодня]
[💵 Доходы]       [🔁 Регулярные траты]
[💰 Добавить семейную трату] [☰ Ещё]   ← семейная кнопка только у премиума с семьёй
```

Всё редкое — в inline-меню «☰ Ещё»: семья, подписка, экспорт CSV, настройки, справка (+ админка для админов).

Кнопки старой клавиатуры (`LEGACY_MENU_BUTTON_KEYS` в `utils/constants.js`) распознаются: бот присылает новую
клавиатуру и открывает ближайший раздел. Нажатие на кнопку из старого сообщения, для которой нет обработчика,
показывает alert `button_outdated`.

## Ввод

| Сообщение | Что происходит |
|-----------|----------------|
| `250 кофе`, `20 USD такси`, `300`, `12,5€ латте` | Трата. Валюта — код или символ сразу после суммы, иначе основная валюта |
| `+50000 зарплата`, `+1000 USD фриланс`, `+300$` | Доход. Без кода — валюта дохода пользователя (`users.income_currency`) |

Категория траты запоминается по описанию (без учёта регистра): если такая трата уже была в доступной категории,
запись создаётся сразу, иначе показывается выбор категории (`category|<id>`).
После записи приходит карточка с кнопками «↩️ Отменить», «🏷 Категория», для премиума — «✏️ Изменить» и «В семью / Из семьи».

## Премиум, подписка и воронка

- **Записи без лимита** для всех. Премиум даёт: бюджеты, полные итоги периода, 160 символов в описании,
  до 5 своих категорий, семейный бюджет, изменение суммы/описания записи (`USER_LIMITS` в `utils/constants.js`).
- **Пробный период** — 14 дней при первой регистрации.
- **Тарифы** (`PREMIUM_TARIFFS`): месячный продаётся как подписка Telegram Stars с автопродлением
  (`createInvoiceLink` с `subscription_period=2592000`, кнопка помечена 🔁), 3/6/12 месяцев — разовые.
  Каждое продление приходит как `successful_payment` с `is_recurring` и продлевает премиум на 30 дней;
  повторная доставка того же `telegram_payment_charge_id` игнорируется. Пока подписка оплачена
  (`premium_transactions.is_recurring`, `subscription_expires_at`), месячный тариф повторно не предлагается.
  Отмена — у пользователя в Telegram: Настройки → Мои звёзды.
- **Уведомления об окончании** (`PremiumLifecycleService`, cron в :25 каждого часа, только 10:00–20:59 по местному
  времени, по одному разу на срок — `user_notifications`): за 2 дня до конца, в первые сутки после и через 7 дней.
  Пользователи с действующей подпиской с автопродлением их не получают.
- **Напоминания** новым пользователям включены по умолчанию (`users.reminder_enabled DEFAULT TRUE`).
- **Источник** — код из ссылки `https://t.me/<бот>?start=<код>` (латиница, цифры, `_`, `-`, до 64 символов),
  сохраняется в `users.source` при первом `/start`.
- **Воронка** (`user_funnel_events`, первое наступление шага): `registered` → `onboarding_completed` → `first_expense` →
  `paywall_viewed` (экран подписки) → `tariffs_viewed` → `paid`. Отчёт: админка → «📈 Воронка» (`panel_funnel_30|90|0`),
  по источникам, плюс «вернулись через неделю» — ручная трата спустя 7+ дней после регистрации.

## Навигация

Переходы по inline-кнопкам редактируют текущее сообщение (`utils/respond.js`), новое сообщение отправляется только
в ответ на ввод текста или команду.

### Обзор, день, карточка записи

| Callback | Описание |
|----------|----------|
| `ov\|<offset>` | Обзор пользовательского периода (`period_start_day`): расходы, доход, остаток, категории, ближайшие регулярные. `offset` 0 — текущий, -1 — предыдущий… В текущем периоде у премиума — шкала общего бюджета и «🎯 N%» у категорий с бюджетом |
| `rp\|<offset>` | Итоги периода (`ReportService.buildReport`) |
| `oc\|<categoryId>\|<offset>\|<page>` | Записи категории за период (по 10 на страницу) |
| `dy\|<offset>\|<page>` | Записи за день (0 — сегодня, -1 — вчера…) |
| `fd\|<page>` | Семейные записи за сегодня |
| `ex\|<id>\|<back>` | Карточка записи |
| `xd\|<id>\|<back>` | Удалить запись (для свежей — «Отменить») |
| `xc\|<id>\|<back>` → `xs\|<id>\|<categoryId>\|<back>` | Сменить категорию |
| `xe\|<id>` | Изменить сумму/описание следующим сообщением (премиум) |
| `xf\|<id>\|<back>` / `xu\|<id>\|<back>` | Перенести в семейный бюджет / убрать из него (премиум) |
| `noop` | Номер страницы в пагинации |

`<back>` — экран, куда возвращается карточка: `d.<offset>.<page>`, `c.<categoryId>.<offset>.<page>`, `f.<page>` или `n`
(свежее подтверждение без кнопки «Назад»). Шаблон — `BACK_VIEW_PATTERN` в `handlers/ExpenseHandlers.js`.

### Доходы

| Callback | Описание |
|----------|----------|
| `income_menu` | Доходы за текущий период: нумерованный список, итог в основной валюте, остаток |
| `in\|<id>` | Карточка дохода |
| `income_delete\|<id>` | Удалить доход из карточки |
| `income_undo\|<id>` | Отменить только что записанный доход |
| `income_add` | Ввод дохода (состояние `adding_income`) |
| `income_currency` / `change_income_currency` | Выбор валюты дохода (из меню доходов / из настроек валют) |
| `set_income_currency\|CUR\|origin` | Установка валюты дохода (`origin`: `income` / `settings`) |

### Регулярные траты

| Callback | Описание |
|----------|----------|
| `recurring_menu` | Нумерованный список, даты следующей записи, итог в месяц |
| `rc\|<id>` | Карточка регулярной траты |
| `recurring_add` | Создание: сумма и описание (`adding_recurring`) → число месяца (`adding_recurring_day`) → категория |
| `recurring_category\|<id>` | Выбор категории и сохранение |
| `recurring_delete\|<id>` | Удаление (уже записанные траты остаются) |

Cron каждые 15 минут записывает трату в расходы, когда в локальном дне пользователя наступает число списания
(в коротких месяцах — последний день). За месяц — не более одной записи (`recurring_expenses.last_charged_month`),
пропущенные месяцы задним числом не досписываются. Если при создании число в текущем месяце уже прошло —
первая запись в следующем месяце; если оно сегодня — запись сразу. Лимит записей (`MAX_NOTES_COUNT`) действует и здесь:
при достижении лимита трата за месяц пропускается, пользователь получает уведомление.
Авто-записи (`expenses.recurring_expense_id`) не считаются ручными записями для напоминалок.

### Бюджеты (премиум)

| Callback | Описание |
|----------|----------|
| `bg_menu` | Бюджеты на текущий период: потрачено / лимит, шкала, остаток или перерасход. Без премиума — описание и кнопка премиума |
| `bg\|<id>` | Карточка бюджета: изменить сумму, удалить |
| `bg_cat` | Выбор категории для нового бюджета |
| `bg_add\|<total\|categoryId>` | Ввод лимита следующим сообщением (состояние `setting_budget:<цель>`), `10000` или `150 USD`; существующий бюджет перезаписывается |
| `bg_del\|<id>` | Удалить бюджет |

Бюджет (`category_budgets`) — лимит на пользовательский период, общий (`category_name IS NULL`) или на категорию
(по имени, как группирует обзор). Траты и лимит пересчитываются в основную валюту по текущему курсу.
После записи траты (ручной, смены категории, регулярной) `BudgetService.checkAfterExpense` проверяет бюджет категории
и общий: на 80% и при превышении приходит предупреждение, каждое по разу за период (`user_notifications`
`budget_80` / `budget_100`, ключ `<id бюджета>:<начало периода>`); после превышения 80% уже не присылается.

### Итоги периода

Все: расходы, сравнение с прошлым периодом, доход и остаток, топ-3 категорий и описание полной версии.
Премиум: каждая категория с изменением к прошлому периоду и шкалой, категории без трат, бюджеты (заведённые
не позже последнего дня периода), средняя трата в день (для текущего периода — по прошедшим дням), самая крупная трата.
Cron в :35 каждого часа: в первые 3 дня нового периода, 10:00–20:59 по местному времени, присылает итоги прошлого
периода пользователям с ручными тратами за 45 дней — по разу за период (`user_notifications` `period_report`),
только если в прошлом периоде были траты.

### «☰ Ещё» и настройки

| Callback | Описание |
|----------|----------|
| `menu`, `back_to_menu` | «☰ Ещё» |
| `family`, `premium_subscription`, `export`, `help` | Разделы «Ещё» |
| `settings`, `back_to_settings` | Настройки: текущие значения в тексте, кнопки в 2 колонки |
| `settings_currencies` | Основная валюта и валюта дохода |
| `change_currency` → `set_currency\|CUR` | Основная валюта (в онбординге — переход к часовому поясу) |
| `configure_reminder_hours` | Напоминания: вкл/выкл (`toggle_reminders`) и часы (`toggle_reminder_hour\|H`, `save_reminder_hours`, `clear_reminder_hours`) |
| `change_timezone`, `tz\|`, `time\|` | Часовой пояс |
| `change_language`, `set_language\|` | Язык |
| `change_period_start` | Число начала периода |
| `custom_categories*` | Кастомные категории (премиум) |
| `bug_report` | Баг-репорт / идея (из справки) |

Без премиума раздел «Семья» показывает описание и кнопку «⭐️ Попробовать премиум».

## Структура навигации

```
Reply-клавиатура
├── 📊 Обзор месяца (ov|)
│   ├── ◀️ / ▶️ периоды (ov|offset)
│   ├── Категория (oc|) → Карточка (ex|)
│   ├── 🎯 Бюджеты (bg_menu) → Категория (bg_cat) / Карточка (bg|)
│   └── 📄 Итоги (rp|offset)
├── 📅 Сегодня (dy|)
│   ├── ◀️ / ▶️ дни, ‹ › страницы
│   └── Номер записи → Карточка (ex|)
├── 💵 Доходы (income_menu) → Карточка (in|)
├── 🔁 Регулярные траты (recurring_menu) → Карточка (rc|)
├── 💰 Семейная трата (премиум + семья)
└── ☰ Ещё (menu)
    ├── Семья (family) → … → Записи за сегодня (fd|) → Карточка (ex|)
    ├── Подписка (premium_subscription)
    ├── Экспорт CSV (export)
    ├── Настройки (settings)
    │   ├── Валюты (settings_currencies)
    │   ├── Напоминания (configure_reminder_hours)
    │   ├── Часовой пояс / Язык / Начало периода
    │   └── Кастомные категории
    └── Справка (help) → Баг-репорт (bug_report)
```

## Примечания

- Все callback actions обёрнуты в `errorHandler`
- Состояния ввода (доход, регулярная трата, бюджет, семейная трата и др.) хранятся в `StateService` и сбрасываются при нажатии
  любой inline-кнопки (`stateCleanupMiddleware`); ожидание новой суммы/описания записи живёт до ввода или «Отмена»
- Локализация: 13 языков, ключ без перевода показывается как есть — новые ключи нужно добавлять во все `src/locales/*.js`
